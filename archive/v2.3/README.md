# GanttPro 2.3 (archive)

Ancienne version de GanttPro, conservée pour mémoire. Elle n'est **plus maintenue ni testée** : utilisez
`GanttPro.html` à la racine du dépôt (version 3), qui ouvre aussi les fichiers de projet de la 2.3.

Contenu : `GanttPro.html` (application 2.3), `update-csp.py` (outil de CSP de la 2.3) et `test_gantt.py`
(ses tests de bout en bout). Les écarts entre la 2.3 et la version 3 sont décrits dans l'annexe A du cahier des
charges fonctionnel.
